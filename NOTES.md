# Project notes (for picking this up in a new session)

Written 2026-11-10. This is the public/shareable copy of the CAT pricing tool. It deliberately contains **no discount-tier data**.

## Working rules from the owner

- **No judgment calls.** If something is ambiguous, missing, or a choice between reasonable options, stop and ask first. Do not pick a best guess and disclose it afterwards.
- **Confirm before substituting a data source.** If the named source cannot support the request, ask before using a different one.
- Ground rules for pricing work: verify page numbers, check calculations, apply the correct multipliers.
- Visual style: dark navy card-based UI (already in `style.css`).

## What the tool does

- **Lookup**: search part number / description / keyword; section filter; 150-result cap.
- **Quote Builder**: qty and a per-line multiplier; totals for List, Savings, Net; copy as CSV; print.
- **Discount Calculator**: multiplier <-> % off <-> net price.
- Net = list x multiplier, rounded to cents. Blank multiplier = list only.
- No built-in tiers. The user types their own multiplier or % off.

## Pricing rules baked into `data.js`

- One price column, `list`. It is the **tariff-inclusive** price: published list x 1.035 (3.5% tariff), **rounded half up** to the dollar.
- **No tariff (price = plain list)** for:
  - complete hinges (hinge section, except the hinge add-on rows),
  - pivots (except the four CAT-EPT rows),
  - any row where the source data itself showed no tariff.
- Hinge add-ons (quick connects, rewires, hospital tip, VD connector, etc.) **are** tariffed.
- Catalog PDF page hints (`pdfPages`) cover only about 23% of rows. Many SKUs are not printed in the 36-page glossy catalog. No hint does not mean a wrong price.
- Part numbers repeat across sections by design (e.g. the same code is a complete lockset in one section and a chassis-only retrofit in another). Never merge records; show the context line.

## Limits and known gaps

- The browser UI was **not tested in a live browser** before the first push. Open `index.html` and exercise search, the multiplier boxes, Add to Quote, CSV copy and the calculator.
- `data.js` was generated by a script that is **not in this repo** (it needs the internal price list, which is intentionally kept out). To change prices, edit `data.js` or rebuild it from the original source on the original machine.
- Possible improvements: hinge lead-length and option-code add-ons, more reliable page citations (needs OCR/layout-aware extraction rather than substring matching), saving quotes between sessions.
- GitHub Pages is **off**. A private repo needs a paid plan for Pages; making the repo public would expose the price data.

## Do not

- Do not add tier multipliers, tier net prices, or the source spreadsheet to this repo.
- Do not commit tokens or credentials.
